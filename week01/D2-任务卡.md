## 今天只需要掌握三样东西

**1. 变量与类型**
```python
name = "张伟"        # 字符串 str
age = 18             # 整数 int
is_active = True     # 布尔 bool
```
变量就是给数据起个名字，不需要声明类型，直接赋值。

**2. 字符串常用方法**（今天只用到 4 个）
```python
"ABC".lower()        # 'abc'      转小写
"138".zfill(11)      # '00000000138'  左侧补零到指定长度
"张" + "伟"           # '张伟'      拼接
"".join(["张", "伟"])  # '张伟'      把列表拼成字符串
```

**3. f-string**（这是今天的重点，以后每天都在用）
```python
name = "张伟"
print(f"用户名是 {name}")        # 用户名是 张伟
print(f"总共 {3 + 4} 条")        # 总共 7 条
print(f"{name:<6}|")             # 左对齐占 6 格
print(f"{3:03d}")                # 003，补零到 3 位
```

## 任务

做一个"注册测试数据生成器"，一次生成 20 条用户数据并打印成表格。

打开 `week01/d2_test_data.py`，里面已经有函数框架、数据素材和一个自动校验器。**你要做的是把 5 个 `NotImplementedError` 换成真正的代码。**

| 函数 | 要做的事 |
|---|---|
| `gen_name()` | 生成 2~4 个字的随机中文姓名 |
| `gen_phone()` | 生成 11 位手机号，号段要合法 |
| `gen_email(prefix)` | 用传入的前缀拼一个全小写邮箱 |
| `gen_user(index)` | 把上面三个组装成字典 |
| `print_table(users)` | 打印成对齐的表格 |

## 验收标准

跑起来后底部会自动校验，**6 项全 PASS 才算完成**：

| # | 检查项 |
|---|---|
| 1 | 生成了 20 条数据 |
| 2 | 每条都有 `id` / `name` / `phone` / `email` 四个键 |
| 3 | 姓名是 2~4 个中文字符 |
| 4 | 手机号匹配 `^1[3-9]\d{9}$`（11 位，第二位 3-9） |
| 5 | 邮箱格式合法且全小写 |
| 6 | 20 个手机号互不重复 |

## 卡住时看这里（只给思路，不给代码）

- 从列表里随机取一个元素：`random.choice(列表)`
- 取一个范围内的随机整数：`random.randint(1, 10)`
- 想随机取 1~2 个字：先 `random.randint(1, 2)` 决定取几个，再循环 `random.choice` 取，最后 `"".join()` 拼起来
- 数字转字符串再补零：`str(数字).zfill(8)`
- f-string 里放变量：`f"值={变量}"`，注意引号前面那个 `f` 不能漏

## 三个新手必踩的坑

1. **`print("用户 {name}")` 不会替换变量** —— 少了 `f`，它就是一串死字符串。
2. **`random` 忘记 `import`** —— 文件顶部已经 `import random` 了，直接用。
3. **手机号用 `int` 存** —— 会丢掉前导零，而且长度不可控。手机号、身份证号一律用字符串。
